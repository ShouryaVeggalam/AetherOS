## What's new

v5.0.0 **Nexus** packages the Platform Extensibility & Enterprise surface on top of
the v2–v4 intelligence stack — without changing the userspace / read-only / HITL
contract.

| Pillar | Package | Operator surface |
|--------|---------|------------------|
| **P1 Plugin SDK** | `plugins/sdk` | YAML manifest · capabilities · sandbox · Rich inspector |
| **P2 Public API & SDK** | `aetheros.api` · `AetherClient` | FastAPI `/api/v1` |
| **P3 Marketplace** | `aetheros.marketplace` | Dashboard **@** Extensions |
| **P4 Policy Studio** | `aetheros.policy` | Dashboard **P** Policies |
| **P5 Enterprise** | `aetheros.enterprise` | Dashboard **E** Enterprise |

Also included from prior generations on this release line:

- v4 Federation · Topology · Distributed Scheduler · Atlas
- v3 Cognition Core · Operational Memory · Causal KG · Consensus · Research Lab
- v2 Resource Graph · Reasoning · Digital Twin · Context · Research Intelligence
- CELESTRA Aether Lab (attention → decompose → plan) under `labs/aether/`

Hotkey remaps for Nexus: **E** Enterprise · **@** Extensions · **P** Policies ·
**#** Predictive · **=** Explainability.

## Architecture overview

Userspace · read-only · human-in-the-loop.

```text
Observe → Reason → Simulate → Explain → Recommend → Human
```

```text
Telemetry → Graph / Cognition → Twin / Scheduler → Policy Studio → Safety
                 ↓
         Public API / AetherClient / Plugins / Marketplace
                 ↓
              Enterprise (RBAC · keys · audit)
```

Diagrams: [architecture.md](../architecture.md) · [architecture/](../architecture/)

Humans approve. No shell. No sudo. No kernel modules. No database migrations in this release.

## Enterprise features

- Organizations & workspaces
- Role-based access control (RBAC)
- API keys for programmatic access
- Append-oriented audit & compliance views
- Dashboard **E** analytics panels

Docs: [enterprise.md](../enterprise.md)

Enterprise controls authenticate and audit **API / operator surfaces**. They do not
grant host shell, sudo, or kernel privileges.

## Known limitations

- Demo GIFs under `docs/screenshots/` may still be placeholders until recorded.
- Third-party plugins are untrusted until sandbox review; do not enable unknown plugins in production.
- Marketplace catalog operations are local/fixture-oriented — not a remote app store SLA.
- Startup import cost grows with platform surface (~100ms+ on cold agents).
- GII `/v9` and Aether Lab modules remain additive research surfaces, not host controllers.
- No automatic GitHub Release publish — draft/tag requires human approval.

## Install

```bash
git clone https://github.com/shouryaveggalam/AetherOS.git
cd AetherOS
python3.12 -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]"
python -m aetheros
```

Or from a release wheel:

```bash
pip install aetheros==5.0.0
python -m aetheros
```
