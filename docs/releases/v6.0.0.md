# AetherOS v6.0.0 — Horizon

**Codename:** Horizon  
**Theme:** Planetary-scale *observation* and *advice* without actuation  
**License:** MIT  
**Status:** Open-source launch packaging (documentation + platform pillars P1–P5)

> AetherOS remains userspace, read-only, and human-in-the-loop. Horizon adds
> multi-cloud census, infrastructure twins, a global knowledge graph, planetary
> placement recommendations, and a Rich observatory — **never** deploys workloads
> or mutates cloud / Kubernetes control planes.

## What's new

### Cloud Federation (P1)

- Read-only adapters for AWS, Azure, GCP, Kubernetes, Docker, and Edge
- Immutable infrastructure snapshots + federation health
- No credentials in models; no provision / delete / restart

Docs: [cloud_federation.md](../cloud_federation.md)

### Infrastructure Digital Twin (P2)

- Clone → scenario → evaluate → diff
- Built-in scenarios: region outage, node failure, latency, GPU expansion, surge, disk failure, custom
- Live baselines remain untouched

Docs: [infrastructure_twin.md](../infrastructure_twin.md)

### Global Knowledge Graph (P3)

- Verified Horizon relationships with evidence indexes
- Validation fails closed; never fabricates edges

Docs: [global_knowledge_graph.md](../global_knowledge_graph.md)

### Planetary Scheduler (P4)

- Region → datacenter → cluster → node scoring
- Constraints + twin-backed simulation + top-5 trade-offs
- Status always **Simulation Only**

Docs: [planetary_scheduler.md](../planetary_scheduler.md)

### Horizon Observatory (P5)

- Rich presentation shell: Overview · Cloud · Topology · Knowledge · Scheduler · Twin · Consensus · Research · Health
- Keys: **O C T K W D G R H** · **Q** quit
- Entry: `aetheros-horizon`

Docs: [horizon_observatory.md](../horizon_observatory.md)

## Install

```bash
git clone https://github.com/ShouryaVeggalam/AetherOS.git
cd AetherOS
python3.12 -m venv .venv && source .venv/bin/activate
pip install -U pip && pip install -e ".[dev]"

aetheros
aetheros-horizon
uvicorn aetheros.api.app:app --reload
```

See [installation.md](../installation.md).

## Upgrade notes

1. Reinstall editable / wheel after pull: `pip install -e ".[dev]"`.
2. Try `aetheros-horizon` for global views without changing your ops workflows.
3. Treat planetary and twin outputs as **advice** — wire any apply path outside AetherOS under your own change control.
