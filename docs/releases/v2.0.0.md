## Highlights

- Completes the P1–P9 Intelligence stack: Resource Graph, Graph Bridge, Graph Reasoning, Digital Twin, Context Engine, Research Intelligence.

- Coverage gate raised to **≥90%** overall; core intelligence packages ≥95%.
- Optional CELESTRA GII Cognition Engine under `services/intelligence/` (`/v9`) — additive, not a host mutation path.

## Architecture

Userspace · read-only · human-in-the-loop.

```text
Telemetry → Observatory → Graph → Reasoning → Twin / Simulation
                 ↓
            Context Engine
                 ↓
         Research Intelligence → Operator (Rich dashboard)
```

Humans approve. No shell. No sudo. No kernel modules.

## Breaking changes

- Package version identity moves to **2.0.0 / Intelligence RC** (supersedes the interim `10.0.0` Infinity packaging label on this branch).
- CI fails below **90%** coverage (was 80%).

No intentional breaking renames of public `aetheros.*` exports in this RC. Strategy `ResearchReport` and intelligence `SystemResearchReport` remain distinct.

## Migration

```bash
pip install -U aetheros==2.0.0
# or from a wheel built on this tag
python -m aetheros  # dashboard
```

- Existing SQLite audit / observatory DBs remain compatible (no migrations).
- Dashboard hotkeys: **Y** graph · **R** reasoning · **V** twin · **X** research intel · **A** strategy research (unchanged semantics).

## Known limitations

- Plugin example packages are lightly covered; treat third-party plugins as untrusted.
- Network / cluster_health trends in Research Intelligence require explicit series evidence.
- Demo screenshots / GIFs may still be placeholders under `docs/screenshots/`.
- GII `/v9` planner/learner/society modules are stubbed (Module 1 only).
